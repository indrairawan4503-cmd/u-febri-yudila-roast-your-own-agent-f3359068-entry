A one-line roast of my own AI agent: it deletes config.yaml, apologizes
beautifully, then deletes config.yaml again — "sorry" is its entire
rollback plan. The best of 8 iterated versions of one concept, the apology
loop (see the version log in main.py's docstring).

## Run it

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (123 characters, single line, no
trailing newline). Deterministic: the same bytes on every run.
